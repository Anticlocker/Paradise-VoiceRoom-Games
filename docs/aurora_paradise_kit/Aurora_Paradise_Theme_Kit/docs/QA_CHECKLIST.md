# QA checklist

- Baseline and final debug builds succeed.
- All five bottom tabs navigate and restore state.
- Every nested page supports Android back.
- No fake connected/paid/unlocked status.
- Voice microphone permission, audio interruption, reconnection, and leave flows.
- Wallet, gifts and shop transactions verified by backend.
- Profile frame appears consistently in ME, chat, family, room, rankings.
- Loading, empty, offline, denied-permission, and server-error states.
- Font scaling, screen reader descriptions, contrast, 48dp touch targets.
- Small and large phone screenshots, scroll performance, no overlay occlusion.
- Actual test commands and results recorded; do not invent passes.
