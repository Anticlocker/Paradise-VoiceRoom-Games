# Discover Premium Assets Kit

24 original illustrated SVG icons, plus PNG (512x512, transparent) and WebP variants. Use **one format** per Android resource; PNG is simplest for `drawable-nodpi`. Source SVGs are editable but Android does not support raw SVG files as ordinary drawable resources. Icons are static glossy vector artwork, not generated 3D models or animations.

Give Antigravity the extracted folder and the two screenshots. Start with `ANTIGRAVITY_DISCOVER_MASTER_PROMPT.md`. No application name has been finalized.

Icon catalog: `preview/asset_catalog.png`. Exact filenames: `asset_manifest.json`.
